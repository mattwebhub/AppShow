# Architecture decision records

One file per decision, numbered, never renumbered. Status is one of `proposed`, `accepted`, `superseded by NNNN`, `rejected`. Edit a record only to change its status; a change of mind is a new record.

Template:

```markdown
# NNNN. Title

Status: proposed | accepted | superseded by NNNN
Date: YYYY-MM-DD

## Context
What situation forces a choice, with facts and file paths.

## Decision
What we will do, in one or two sentences.

## Consequences
What becomes easier, what becomes harder, what we must remember.
```
