# Privacy site

GitHub Pages publishes this directory at <https://mattwebhub.github.io/AppShow/privacy/>.

Edit the policy in the repository-root `PRIVACY.md`. The Pages workflow adds its layout and permalink while building, so there is only one policy source. It copies the existing app icon into the site and uploads only generated website files.

Pull requests build the website for validation. Pushes to `main` that change the policy, site, icon or workflow deploy the result automatically. Manual deployment is also available through the Pages workflow. The page contains no JavaScript, analytics, web fonts or external embedded resources. GitHub handles hosting requests under its own privacy practices.
