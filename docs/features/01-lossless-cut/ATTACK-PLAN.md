# Attack plan: Lossless cut

Companion to `SPIKE.md`. Rules: `planning/tdd-strategy.md` (test first, one behaviour per test, pin before change, no real machine). Tiers T1/T2/T3 from `docs/architecture/07-testability.md` §1. Test files mirror `AppShow/` under `AppShowTests/`. Sizes: S ≤ half a day, M ≤ two days, L ≤ a week.

Dependency graph:

```
P1 model+remap ──┬── P2 persistence+history ──┐
                 ├── P4 transport button ─────┤
                 ├── P3 cuts track ───────────┼── P6 compressed timeline
                 ├── P5 playback jumping ─────┘
                 └── P7 export verification (tests any time; end-to-end run last)
```

P2, P3, P4, P5 can run in parallel once P1 has landed. P6 needs P3 and P5. P7's unit tests can start with P1; its gated end-to-end run is the last step. P2 and P5 need the `screen-2s.mov` fixture and `Support/Fixtures.swift` from milestone 01 (`planning/tdd-strategy.md` "Fixtures"); if those are not ready, ship P1, P3, P4 first.

Every upstream file touched is listed in `planning/upstream-sync.md` "Intentional divergences" as part of the phase.
